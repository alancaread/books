码书：编码与解码的战争

西蒙·辛格（Simon Singh）

2017

The Code Book

30 秒 · 先读这一段

讲什么

本书梳理了从古希腊、古埃及至现代数字革命与量子时代的编码者与译码者攻防演化史及古文字解译过程，重点探讨加密技术如何决定历史转折以及人类能否建立不可破解的保密系统。作者主张，尽管现存所有传统算法密码终将面临被新型计算技术（如量子计算机）攻破的威胁，但基于物理学测不准原理的量子密码将提供物理意义上绝对不可破解的屏障，从而彻底终止编解码之间持续数千年的拉锯战。

适合谁

适合对密码历史、信息安全、数学与物理学应用感兴趣的大众读者，以及希望了解数字时代个人通信隐私与公众监管博弈的读者。

值不值得读

本书将复杂的密码原理与历史政治事件、战争转折及人物命运深度结合，清晰梳理出密码学与数学、计算机及物理学交织发展的演进逻辑。但受限于军事与政府机构的保密政策，书中对部分现代情报机构内部突破及未来量子技术的讨论带有推测成分，且第5章探讨古代失落语言的解译偏离了加密通信的主题。

三个带走

  1. 认识到密码系统的安全核心在于钥匙保密（科克荷夫斯原则）而非隐瞒算法，人为操作疏漏往往是安全链条中最脆弱的一环。
  2. 掌握基于统计特征与逻辑假设的分析方法，利用自然语言字母出现的固定频率差异（频率分析法）破译结构性掩盖的信息。
  3. 理解强加密技术作为数字时代个人防范网络窃听与保障资产隐私的锁钥作用，厘清个人隐私与执法监管之间的权衡问题。

AI 时代怎么读

书里指出，在自动化监听系统（如“梯队”网络）能对大众通讯进行无差别自动筛检拦截的时代，个人需要依靠强加密技术来建立防护隐私的锁钥。
